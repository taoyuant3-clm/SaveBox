# 拾存 SaveBox

在小紅書、瀏覽器、YouTube、LINE 看到有用的貼文、連結、圖片或影片，按「分享 → 拾存」就存好，再也不用到處翻聊天記錄和書籤。

- **一鍵收藏**：任何 App 的「分享」都可以存進拾存，連結、文字、相片、影片都收
- **分類整理**：自己建分類，可改名、移動、排序；未分好的先放「未分類」
- **備註**：每項收藏可加備註，記下為什麼存
- **搜尋**：標題、備註、連結都搜得到
- **快速取用**：一按打開原連結，或複製連結／文字再分享
- **備份／還原**：整份收藏（含相片、影片）匯出成 zip，換手機也帶得走
- 不用註冊、沒有廣告，資料只存在你的手機

## 為什麼做這個

看到好東西時，很多人會傳給自己、截圖或加書籤，結果分散在好幾個地方，要用時找不到。拾存把它們集中在同一個地方，按分類放好，隨時搜得到。

## 安裝

1. 到 [Releases](../../releases/latest) 下載最新的 `SaveBox-<版本>.apk`
2. 手機開啟下載的檔案 → 允許「安裝不明來源的應用程式」→ 安裝
3. 在任何 App 按「分享」，選「拾存」即可存入

Share any link, text, photo or video from any app (browser, YouTube, Xiaohongshu, LINE…) to SaveBox, sort it into your own categories, add notes, and search it later. Full backup/restore to a zip file. No account, no ads, data stays on your phone.
